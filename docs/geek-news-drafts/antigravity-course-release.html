AIプログラミングスクール「バイテックGEEK」は、新コース「Antigravity 開発コース」を追加しました。

Antigravity 開発コースは、GoogleのAIエージェント型の開発ツール「Antigravity」に指示を出しながら、GAS（Google Apps Script）でスプレッドシート・Gmail・カレンダー・Driveの業務を自動化し、社内で使えるツールまで自分で作れるようになるコースです。全10章・49レッスンで構成しています。

追加の背景

Google Workspaceで仕事をしている方の多くは、転記・集計・メール送信・予定登録といった繰り返しの作業を毎日手で行っています。GASを使えばこうした作業は自動化できますが、これまではコードを書けることが前提でした。

Antigravityを使えば、やりたいことを言葉で伝えてAIエージェントに作業を任せられます。本コースでは、AIに任せる範囲や確認の仕方といった「事故を防ぐ使い方」から始め、業務の自動化、社内ツールの制作、社内での運用までを順番に身につけます。

Antigravity 開発コースの概要

  • コース名：Antigravity 開発コース
  • 使用ツール：Antigravity／GAS（Google Apps Script）／Google Workspace／Gemini API
  • 受講形式：オンライン
  • ボリューム：全10章／49レッスン
  • 履修期間：2〜6ヶ月
  • おすすめの方：普段の業務がGoogle環境の方

このコースで作れるようになるもの

  • スプレッドシートの転記・集計・整形の自動化
  • フォームの回答の振り分けや記録、定期実行と失敗時の通知
  • Gmailの下書き作成・差し込みメール、カレンダーへの予定登録、Driveのファイル整理
  • ひな形とシートのデータからドキュメント・スライド・PDFを自動で作る仕組み
  • Gemini APIを使った問い合わせの要約と分類
  • 社内の人だけが使えるGASのWebアプリ（社内ツール）

カリキュラム

第1章　Google環境の全体像と準備（5レッスン）

Gemini・NotebookLM・Workspace Studio・GAS・Antigravityの使い分けを整理し、Antigravityの導入と最初のGASの実行まで進めます。

第2章　事故を防ぐ初期設定（4レッスン）

AIに許す操作の設定、変更内容（差分）の確認、Gitで元に戻せるようにする方法、会社のデータの扱いを学びます。

第3章　依頼と計画（3レッスン）

目的・材料・完成の形・確かめ方をそろえた依頼の仕方と、作る前に計画を出させて確かめる進め方、要件定義書のまとめ方を学びます。

第4章　GASで業務を自動化する（9レッスン）

スプレッドシートの自動処理、メニュー・ボタンからの実行、編集やフォーム回答をきっかけにした処理、定期実行（トリガー）、失敗時の通知、秘密情報の扱いまでを実践します。

第5章　Gmail・カレンダー・Drive・資料をつなぐ（8レッスン）

メールの下書き・記録・差し込み、予定の登録と締め切りの通知、Driveの整理、定型資料とPDFの自動作成を行います。

第6章　Workspace MCPで横断作業をする（発展・2レッスン）

Workspace MCPをAntigravityにつなぎ、Gmail・カレンダー・Drive・シートをまたぐ作業をAIに任せます。

第7章　データとGemini APIを活用する（5レッスン）

シートのデータ分析、グラフとダッシュボードでの見える化、外部データの取り込み、Gemini APIによる要約と分類の自動化を学びます。

第8章　社内ツールを作る（5レッスン）

作るツールを決め、GASで画面のあるWebアプリを作り、社内の人だけが使えるようにします。エラーの調べ方と公開前の確認も扱います。

第9章　エージェントを社内で育てる（4レッスン）

ルールとスキルでAIの作業をそろえ、外部連携の基準、AIに任せる範囲と費用の上限を運用手順にまとめます。

第10章　総合制作（4レッスン）

自社の定型業務を棚卸しし、要件定義・計画・制作・検証を経て、他の人が動かせる運用手順にまとめて引き継ぐところまでを仕上げます。

こんな方におすすめです

  • 普段の業務をGoogle Workspace（スプレッドシート・Gmail・カレンダー・Drive）で行っている方
  • 毎日の転記・集計・メール送信などの繰り返し作業を減らしたい方
  • コードは書けないが、社内で使う小さなツールを自分で作りたい方
  • AIに作業を任せるときの安全な進め方を身につけたい方
