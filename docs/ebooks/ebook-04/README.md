# AI研修タイプ 比較ガイド — 資料の編集方法

この資料は **HTML と CSS だけ** でできています。専用ソフトは不要で、テキストエディタとブラウザがあれば編集できます。

## ファイル構成

```
ebook-04/
├── deck.html          ← 文章・スライドの中身（ここを編集）
├── assets/
│   ├── deck.css       ← 見た目（色・文字サイズ・余白）
│   ├── photo/         ← 研修タイプの写真4枚
│   ├── illus/         ← イラスト（eff/ が「見込める効果」用12枚）
│   ├── logos/         ← 導入事例の企業ロゴ
│   └── biz-logo*.svg  ← 右上のロゴ
└── README.md          ← このファイル
```

## 編集のしかた

1. `deck.html` をテキストエディタで開く（VS Code、メモ帳、テキストエディットなど何でも可）
2. 文章を書き換えて保存する
3. `deck.html` をブラウザ（Chrome推奨）にドラッグ＆ドロップすると、全スライドが縦に並んで表示される
4. ブラウザを再読み込み（`Cmd/Ctrl + R`）すれば編集内容がすぐ反映される

スライド1枚は次のかたまりです。`<figure>` から `</figure>` までが1枚に対応します。

```html
<!-- ===== S2-3 eラーニング 料金 ===== -->
<figure class="slide-shell"><div class="clip">
  <div class="slide">
    ...スライドの中身...
  </div>
</div><figcaption>S2-3 eラーニング 料金</figcaption></figure>
```

- **文章を直す**: タグ（`<p>` や `<span>`）の間にある日本語を書き換える
- **スライドを増やす**: `<figure>` 〜 `</figure>` をまるごとコピーして貼り付け、中身を書き換える
- **スライドを消す**: `<figure>` 〜 `</figure>` をまるごと削除する
- **改行を入れる**: 改行したい位置に `<br>` を書く
- **文字を青くする**: 囲みたい部分を `<b>青くしたい文字</b>` で囲む

`<figcaption>` は編集用のラベルで、PDFや公開ページには出ません。ページ番号は自動採番なので、スライドを増減しても振り直し不要です。

## 気をつけること

- **1スライドは 1280 × 720 ピクセル固定**です。文字を増やしすぎると枠からはみ出して切れます。ブラウザで見て収まっているか必ず確認してください。
- `class="..."` の部分は見た目の指定です。消すとレイアウトが崩れます。
- `assets/` フォルダは `deck.html` と同じ場所に置いたままにしてください。分けると画像が表示されなくなります。
- 色や文字サイズを全体的に変えたいときは `assets/deck.css` の先頭にある `:root { --blue: ...; }` を調整します。

## 編集後の反映について

編集した `deck.html`（画像も差し替えた場合は `assets/` ごと）を返送してください。こちらで次のコマンドを実行すると、公開ページと配布PDFが再生成されます。

```
node scripts/build-ebook.mjs ebook-04 --pdf
```

- 公開ページ: https://biz.bytech.jp/documents/ebook-04
- 配布PDF: https://biz.bytech.jp/assets/docs/ebook-04.pdf

`public/biz/ebooks/ebook-04/` 以下は上記コマンドが作る自動生成物です。直接編集しても次回の生成で上書きされるので、編集は必ず `docs/ebooks/ebook-04/deck.html` に対して行ってください。
